Everything pronotepy does. In TypeScript.

Every corner of the original library was ported faithfully — then made async, typed, and idiomatic for Node.js.

Real PRONOTE encryption

RSA-1024 handshake and AES-128-CBC session encryption, byte-for-byte compatible with the official protocol.

Fully asynchronous

A clean Promise-based API built around await Client.login(...) — no blocking calls, ever.

End-to-end types

Grades, lessons, homework, discussions, menus — every data class is fully typed for autocompletion and safety.

30+ ENT providers

CAS, EduConnect, Open ENT NG, WAYF, HubEduConnect, Oze ENT and more — plug in your school's SSO in one line.

QR code & token login

Log in like the mobile app: scan a QR code once, then reconnect silently with a persistent token.

Every account type

Client, ParentClient and VieScolaireClient cover students, parents and school staff.

Read like the docs, run like production code

A single example, straight from the README.

import { Client } from "pronoteTs";

const client = await Client.login(
  "https://town.pronote.myacademy.fr/pronote/eleve.html",
  "username",
  "password"
);

const period = client.periods[0];
for (const grade of await period.grades()) {
  console.log(`${grade.subject.name}: ${grade.grade}/${grade.outOf}`);
}

for (const hw of await client.homework(new Date())) {
  console.log(hw.description);
}
